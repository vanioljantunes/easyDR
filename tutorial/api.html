Fit it, then draw it

One call for the model, one for the picture, and a shape you had to name

1

The call: easydr()

library(easyDR)

fit <- easydr(alcohol_cancer,
               sm        = "RR",
               shape     = "linear",
               dose.unit = "g/day",
               at        = c(10, 25, 50))
fit

Read the slope as a step, not a group.

An RR of 1.006 per 1 g/day does not mean drinkers run 1.006 times the risk. Each gram per day multiplies the risk by about 1.006, measured against the reference dose. easyDR prints that reference every time, because moving it moves every predicted effect.
2

The five shapes you can name

shapeFitsTerms
"linear"a straight line through the dose1
"log"a straight line through log dose1
"quadratic"dose and dose squared2
"rcs"a restricted cubic spline; knots places them2+
"fp"a fractional polynomial; powers chooses the pair2

The shape is a claim about the biology, so it belongs in your protocol with a reason beside it: the dose range your readers care about, whether a threshold or a flattening is plausible here, what comparable reviews fitted. easyDR has no default and ranks nothing. Leave the argument out and the error lists what you may write. 

easydr(alcohol_cancer, sm = "RR")
Error: easydr: name the `shape` you want fitted. There is no default, because the shape is a claim about the biology and belongs in your protocol with a reason beside it. Name one of: shape = "linear" a straight line through the dose shape = "log" a straight line through log dose shape = "quadratic" dose and dose squared shape = "rcs" a restricted cubic spline, see `knots` shape = "fp" a fractional polynomial, see `powers`

A shape with more than one term prints a departure-from-linearity test, which a straight line cannot, and prints no single slope, because no single number describes a curve.

3

Draw it: easydr_curve()

It takes the object easydr() returned. The fit computed every number on the picture; these arguments choose what appears and how. 

# the defaults
easydr_curve(fit)

# titled, labelled, pinned, with the prediction band
easydr_curve(fit,
             main  = "Alcohol and colorectal cancer",
             xlab  = "Alcohol intake (g/day)",
             ylab  = "Risk ratio",
             ylim  = c(0.9, 1.8),
             round = 2,
             prediction = TRUE)

# the corner box off, if the caption carries the numbers
easydr_curve(fit, result = FALSE)
