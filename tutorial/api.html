That slope is not an effect of being exposed.

An IRR of 1.006 per 1 g/day does not mean drinkers are at 1.006 times the rate. It means each gram per day multiplies the rate by about 1.006, measured against the reference dose, which is why the reference is always printed. Change the reference and every predicted effect changes with it.
2

Why shape has no default

It would be easy to rank the candidate shapes and fit the winner. easyDR does not, because the ranking is only defensible under conditions the default call does not meet.

  • REML cannot compare them. It conditions on the fixed effects, so a line and a curve are scored on different likelihoods.
  • A two-stage criterion moves with the units. Multiplying the dose by 1000 changes no model at all and moves the two-stage AIC on this data by over a hundred points.
  • The top of the table is usually a tie. On these eight cohorts, fourteen of the forty-two candidates sit within 2 AIC of the best.

So the shape is yours, chosen for reasons you can write down: the biology, the dose range your readers care about, what comparable reviews did. easydr_select() runs the comparison properly when you want it, refitting one-stage by maximum likelihood and saying so. 

sel <- easydr_select(alcohol_cancer, sm = "IRR",
                     dose.unit = "g/day")

A line, and the same studies as a curve

Changing one argument changes the model and nothing else. A curve prints a departure-from-linearity test, which a straight line cannot, and prints no single slope, because no single number describes it.

Every estimate here comes from dosresmeta. easyDR chose none of them.
