One call, and four things to do with it

Dose-response meta-analysis argued the way the meta package argues

1

There is no formula argument

What a dose-response usually asks of you

# reshape, compute the log ratio, compute its
# standard error, then describe the model as
# a formula over columns you just made
fit <- dosresmeta(formula = logrr ~ dose,
                  type = type, id = id, se = se,
                  cases = cases, n = peryears,
                  data = d)

You had to derive every one of those columns yourself. logrr ~ dose describes your spreadsheet. It says nothing about the review you are writing.

What easyDR asks

# name the measure the studies report, and
# the shape you decided on
fit <- easydr(alcohol_cancer, sm = "IRR",
               shape = "linear",
               dose.unit = "g/day",
               at = c(10, 25, 50))
sm picks the columns.

It also fixes which covariance approximation is available and what scale the results come back on. easyDR derives the contrasts, the standard errors and the within-study covariances from the table you already extracted.
2

The family

One function fits. The other four take what it returned. The package exports nothing else.

FunctionWhat it gives youWhat it will not do
easydr() The pooled dose-response, its heterogeneity, the prediction interval, the predicted effects, the viability check and a name for the curve. Choose the shape. shape has no default, and nothing ranks the candidates for you.
easydr_forest() One row per study: its own trend, its weight, and the pooled diamond underneath. Invent rows for a one-stage fit, which never produces per-study estimates.
easydr_curve() The fitted curve with its confidence band, the reported doses marked, the prediction band on request. Hide that a dose sits beyond the observed range.
easydr_loo() The curve refitted with each study left out in turn, drawn over the pooled one, ranked by how far the result moved. Attach a p value. The refits are not independent.
easydr_funnel() The study trends against their standard errors, with Egger's regression test for asymmetry. Say the asymmetry is publication bias.
3

Two checks you no longer have to remember

Two things go wrong in a dose-response review. The included studies could never have supported a model in the first place, or the fitted curve gets described in words the literature does not use.

easydr() runs both checks and prints both. The viability check reads the prepared analysis frame, so it reports the reference category the fit used. It does not guess that a zero dose is one. 

fit <- easydr(alcohol_cancer, sm = "IRR",
               shape = "linear")

fit$viability   # the per-study table
fit$curve_label # "monotonic increasing"
