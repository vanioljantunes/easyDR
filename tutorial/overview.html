What this package is

easyDR is the package the book leans on, and it is deliberately small. It carries the two steps students repeatedly get wrong, and leaves the modelling to dosresmeta by Crippa and Orsini, which is validated, peer reviewed, and already does that job well.

dr_viability() Checks whether a dataset can support a dose-response model at all, before any fitting.
curve_shape() Names the shape of a fitted curve in the vocabulary the literature uses.

What you get

✓
A check that runs before the model.

The commonest reason a dose-response meta-analysis fails is not the model; it is that the included studies never could have supported one. dr_viability() reports that per study, with the reason, rather than letting a fit fail later for a reason that reads as numerical.

✓
A name for the curve.

curve_shape() returns one of five labels, so the results paragraph and the figure agree with each other, and with the words the field already uses.

✓
No estimator of its own.

Every estimate in the book comes from dosresmeta. This package prepares and interprets; it does not compute a pooled slope, and it does not wrap dosresmeta in a layer you then have to learn.

What you do not get, so you are not surprised: no fitting function, no plotting, no bundled datasets. The examples use dosresmeta and the data dosresmeta ships.
