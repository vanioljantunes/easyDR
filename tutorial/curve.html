Fit it, then name it

The model is delegated; the words for the curve are not

The model itself: dosresmeta

This package does not fit anything. The book's statistics chapter fits with dosresmeta, on the eight-cohort alcohol and colorectal cancer example that package ships. 

library(dosresmeta)
data(alcohol_crc)

fit <- dosresmeta(formula = logrr ~ dose, type = type,
                  id = id, se = se, cases = cases,
                  n = peryears, data = alcohol_crc)

summary(fit)$coefficients
Estimate Std. Error z Pr(>|z|) (Intercept) 0.0064375 0.001352 4.761344 1.9e-06
That coefficient is not an intercept.

The model has no intercept: it is suppressed, because every contrast is against the study's own reference category. So the number labelled (Intercept) is the dose slope, on the log scale, per unit of dose.

Here it is 0.006438 per gram per day, which exponentiates to a rate ratio of 1.0065 per gram per day. Reporting it as an intercept is a mistake the label invites.
7

After the model: curve_shape()

A fitted curve has to be described in words at some point, and the words should be the ones the literature uses. Feed it the predicted effects and it returns one of five labels. 

pred <- predict(fit, newdata = grid, expo = FALSE)

curve_shape(grid$dose, pred$pred)
#> [1] "positive association"

Emax is judged against the curve's own steepest step rather than its overall range, which is what separates a genuine plateau from a curve that merely decelerates.

The labels describe how the effect changes from one dose to the next, not where the curve sits, so log effects and the ratios themselves give the same answer.
