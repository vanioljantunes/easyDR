What to do with the fit

Four questions, four calls, each taking the object easydr() returned

1

What did each study contribute? easydr_forest()

fit <- easydr(alcohol_cancer, sm = "IRR",
               shape = "linear",
               dose.unit = "g/day")

easydr_forest(fit)

# a curve has no single trend, so the
# rows become one dose
easydr_forest(rcs, at = 25)

A dose-response study contributes a trend, not an effect, so that is what a row shows: the study's own slope from the two-stage first stage. These are the engine's own estimates, not something recomputed for the picture, and the function hands the table back so you can check them.

A one-stage fit has no rows.

It estimates every study inside a single model and never produces a per-study coefficient. Rather than draw the pooled line eight times, this refuses and says to refit with proc = "2stage".
2

Is one study carrying it? easydr_loo()

cvd <- easydr(alcohol_cvd, sm = "RR",
               shape = "linear",
               dose.unit = "g/day")

# draws the figure beside this
easydr_loo(cvd, quiet = TRUE)

# the table alone, nothing drawn
loo <- easydr_loo(cvd, quiet = TRUE, plot = FALSE)
loo$table

Curve A is the fit without Bianchi, and it is the one that walks away from the black line. Dropping that cohort takes I-squared from 71% to nothing: it was most of the heterogeneity.

The rows carry no p value. The refits share almost all their data, so they are not independent and a shift is not a test.

Does a characteristic explain it? easydr_metareg() and easydr_bubble()

mr <- easydr_metareg(cvd, ~ design)
mr

easydr_bubble(mr, labels = TRUE)

The line is the regression's own.

The bubbles are the unadjusted study trends and the red bars come from easydr_metareg(), not from a fresh regression through the points. That is why a study can sit off the bar: the distance is the residual heterogeneity the printout quantifies.
4

Are the small studies different? easydr_funnel()

f <- easydr_funnel(fit, labels = TRUE)

f$egger
#> $intercept  -1.0879
#> $se          1.2204
#> $t          -0.8914  on 6 df
#> $p           0.4070
Egger, not Deeks.

Deeks' funnel asymmetry test is for diagnostic test accuracy, where the effective sample size is the sensible axis, and it does not apply here. A dose-response review has one trend per study with a standard error, which is the setting Egger's regression was written for.

With eight studies the test has little power, so the figure says so above the panel rather than leaving it to be remembered. Asymmetry has several causes and publication bias is only one.

Every one of these returns the table it drew, so the numbers behind a picture can be checked against the fit they came from.
