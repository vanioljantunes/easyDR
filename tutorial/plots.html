What to do with the fit

Three questions, three calls, each taking the object easydr() returned

1

What did each study contribute? easydr_forest()

fit <- easydr(alcohol_cancer, sm = "RR",
               shape = "linear",
               dose.unit = "g/day")

easydr_forest(fit)

# a curve has no single trend, so the
# rows become one dose
easydr_forest(rcs, at = 25)

Each row is one study's own slope, taken from the two-stage first stage. That slope is what a dose-response study contributes: a trend across its exposure categories. The function hands the table back, so you can check the numbers against the fit.

A one-stage fit has no rows.

It estimates every study inside a single model and never produces a per-study coefficient. Drawing the pooled line once per study would look like data, so this stops instead and says to refit with proc = "2stage".
2

Is one study carrying it? easydr_loo()

cvd <- easydr(alcohol_cvd, sm = "RR",
               shape = "linear",
               dose.unit = "g/day")

# draws the figure beside this
easydr_loo(cvd, quiet = TRUE)

# the table alone, nothing drawn
loo <- easydr_loo(cvd, quiet = TRUE, plot = FALSE)
loo$table

Curve A is the fit without Bianchi, and it walks furthest from the black line. Dropping that cohort takes I2 from 71% to nothing, so most of the heterogeneity was that one study.

The rows carry no p value. The refits share almost all their data, so a shift between them describes the data rather than testing it.

3

Are the small studies different? easydr_funnel()

f <- easydr_funnel(fit, labels = TRUE)

f$egger
#> $intercept  -1.0879
#> $se          1.2204
#> $t          -0.8914  on 6 df
#> $p           0.4070
Egger, not Deeks.

Deeks' funnel asymmetry test belongs to diagnostic test accuracy, where the effective sample size is the sensible axis. A dose-response review has one trend per study with a standard error, which is the setting Egger wrote his regression for.

With eight studies the test has little power. The figure prints that warning above the panel. Asymmetry has several causes and publication bias is only one of them.

Each of these returns the table it drew, so you can check the numbers behind a picture against the fit they came from.
